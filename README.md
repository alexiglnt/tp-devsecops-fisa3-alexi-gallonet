# DevSecOps_TP

Petite API Node.js/Express de prise de notes, développée par un collègue à l'aide d'un assistant IA en une seule session, sans relecture. On vous demande de la sécuriser avant sa mise en production. Ce code sera votre base pour les 5 sessions de TP.

## Lancer l'application en local

```bash
npm install
npm start
```

L'application démarre sur `http://localhost:3000`.

## Lancer les tests

```bash
npm test
```

## Endpoints

Aucune documentation d'API n'a été laissée par l'auteur d'origine. À vous de l'explorer (code source dans `src/routes/`).
